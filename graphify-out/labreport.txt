Testing Approach for Login Module
The Login module testing is performed using Black Box Testing. In this approach, the
internal structure or implementation of the system is not considered. Instead, the system is
tested based on inputs and expected outputs.
In the above test cases, different input conditions such as valid credentials and missing
password are provided to the system. The system’s behavior is then observed, such as
whether it allows access or shows an error message.
Since the testing focuses only on user interaction and system response without analyzing
the internal code logic, this module follows the Black Box Testing approach.
